A standard-library Python program that writes a one-sentence startup pitch to `/output/entry.txt`. The pitch is for a toilet-flushing service. It sounds like a joke, but snowbirds pay $30 a week for it. Their Florida condos sit empty for months, and without a weekly flush the drain traps dry out and let in sewer gas and roaches. The sentence is built to land in two beats: the first clause sounds absurd, and the second gives the real reason someone would pay for it.

## Run it

```sh
python3 main.py
```
